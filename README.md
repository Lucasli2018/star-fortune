# 星语 · 星座运势

> 神秘星空风格的星座运势预测网站工具 —— 单文件、零依赖、离线可用。

在线体验（部署后）：`https://gitee.com/li-luoqiang/star-fortune`

---

## ✨ 功能特性

- **12 星座选择** —— 网格卡片展示星座符号、日期区间与星象元素，点击即时切换
- **生日自动识别** —— 输入生日（月/日）自动匹配所属星座
- **多周期运势** —— 今日 / 明日 / 本周 / 本月 一键切换，文案与指数随周期自适应
- **综合 + 分项指数** —— 环形综合指数，外加 爱情 / 事业 / 财运 / 健康 / 人际 5 项进度条
- **幸运要素** —— 幸运数字、幸运颜色（带色块预览）、速配星座
- **运势详解** —— 分项解读 + 今日宜 / 忌 + 每日箴言
- **星座配对** —— 双下拉选择，基于元素相性（火/土/风/水）的确定性评分与解读
- **记忆上次选择** —— 通过 `localStorage` 记住上次所选星座与生日
- **沉浸视觉** —— Canvas 星空闪烁 + 流星、玻璃拟态卡片、每个星座专属主色、中文衬线标题 + Orbitron 数字

### 运势如何生成？

运势由 **「日期 + 星座」** 作为种子的确定性伪随机算法（xfnv1a 哈希 + mulberry32）生成：

- 同一星座在**同一天**的运势结果**始终一致**，不会刷新就跳变
- 不同日期自然产生差异，符合「每日运势」的直觉
- 星座配对分数做了**对称处理**（A 配 B = B 配 A），且可复现
- 文案来自内置语料库，按指数区间抽取，无需联网或密钥

> ⚠️ **免责声明**：本工具所有运势、配对、箴言均为基于算法的**娱乐性内容**，不具备任何科学依据，请勿作为人生决策依据。

## 🚀 本地运行

直接双击 `index.html` 即可在浏览器打开，无需任何构建步骤。

如需本地起一个静态服务器：

```bash
# 任选其一
python -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080`。
